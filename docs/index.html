Why TerraView

Your plan, without the round trip.

Atlantis is great for approval. It is a slow way to answer “what will this change?”. TerraView gives you the answer locally, in seconds.

No Atlantis wait

Generate a plan locally, pipe it into TerraView, and inspect the graph before you open the MR.

Dependency-aware

Upstream and downstream resources are reconstructed from configuration, depends_on, and prior state.

Actionable commands

Copy terraform -target or Atlantis commands for the exact resource you are reviewing.

Getting started

From plan to preview in two commands.

TerraView is a local server. It reads plan JSON from stdin, opens a browser, and never sends your plan anywhere.

terminal 
# 1. Generate a plan
terraform plan -out=tfplan

# 2. Pipe it into TerraView
terraform show -json tfplan | terraview
  1. 1

    Plan locally

    Use your normal workspace, credentials, and variables. TerraView only consumes the JSON output.

  2. 2

    Inspect the graph

    Your browser opens on a DAG grouped by dependency level, with add, modify, destroy, and existing resources.

  3. 3

    Copy the command

    Click a node to see the diff, dependencies, and the targeted Atlantis command for that resource.

Example

A VPC, a subnet, and an EKS cluster.

This is the kind of chain TerraView reconstructs from a real plan. No guessing which resource to target.

main.tf 
resource "aws_vpc" "main" {
  cidr_block = "10.0.0.0/16"
}

resource "aws_subnet" "private" {
  vpc_id     = aws_vpc.main.id
  cidr_block = "10.0.2.0/24"
}

resource "aws_eks_cluster" "app" {
  vpc_config {
    subnet_ids = [aws_subnet.private.id]
  }
}
aws_vpc.main ADD +
aws_subnet.private MODIFY ~
aws_eks_cluster.app EXISTING
TerraView sees the chain. Click aws_subnet.private to inspect the CIDR diff and copy atlantis plan -- -target=aws_subnet.private.
Features

Everything you need to review a plan.

Built for Terraform reviewers who want signal, not another dashboard.

Interactive DAG

Topological levels, zoom, pan, and upstream/downstream visibility.

Resource diff inspector

Formatted before/after JSON with line-level highlights for inline policies and nested values.

Atlantis commands

Copy plan, apply, destroy, import, and targeted commands per resource.

Search and action filters

Focus on add, modify, destroy, or existing resources — including a dedicated destroy view.

Static CI reports

Export a single HTML file and attach it to a CI job or review.

Git-aware context

See the repository path, current branch, and plan source directly in the UI.

CI-ready

Attach a plan report to every pull request.

No server, no plugin, no extra infrastructure. Generate the report and upload it as an artifact.

ci.sh 
terraform show -json tfplan > plan.json
terraview -static -in plan.json -out terraview-report.html

One file to share

The report embeds the graph data and opens in any browser. Upload it as a GitHub Actions or GitLab CI artifact, or link it from a review.
